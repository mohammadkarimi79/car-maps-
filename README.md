# پوشه‌نگار | راهنمای خیلی ساده

این پروژه یک برنامهٔ اندرویدی فارسی برای نگهداری عکس‌ها در پوشه‌های تو در تو است. عکس‌های انتخاب‌شده داخل فضای خصوصی برنامه کپی می‌شوند و برای انتخاب عکس، مجوز گستردهٔ حافظه لازم نیست.

## ساخت برنامه در Android Studio

1. Android Studio را روی رایانه نصب و اجرا کنید. در نخستین اجرا، اجازه دهید اجزای پیشنهادی Android SDK نصب شوند.
2. فایل ZIP پروژه را از حالت فشرده خارج کنید.
3. در صفحهٔ آغاز Android Studio روی **Open** بزنید و پوشهٔ `PooshehNegar` را که فایل `settings.gradle.kts` داخل آن است انتخاب کنید.
4. اگر پیام **Trust Project** آمد، **Trust Project** را انتخاب کنید. صبر کنید تا **Gradle Sync** تمام شود؛ اگر نصب SDK یا دانلود Gradle پیشنهاد شد، آن را تأیید کنید.
5. برای اجرای مستقیم، یک گوشی را با کابل USB وصل کنید و USB debugging را فعال کنید، یا از **Device Manager** یک شبیه‌ساز بسازید. سپس دکمهٔ سبز ▶ کنار نام دستگاه را بزنید.
6. برای ساخت فایل نصب، از منو **Build > Build Bundle(s) / APK(s) > Build APK(s)** را انتخاب کنید. پس از اتمام، Android Studio لینک **locate** را نشان می‌دهد. فایل APK در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## استفاده از برنامه

- در صفحهٔ اصلی، **پوشه جدید** را بزنید، نام وارد کنید و **ساخت** را انتخاب کنید.
- روی نام هر پوشه بزنید تا وارد آن شوید. با دکمهٔ بازگشت خود گوشی به پوشهٔ قبلی برمی‌گردید.
- برای افزودن تصویر، **افزودن عکس از گالری** را بزنید و یک عکس انتخاب کنید. تصویر در پوشهٔ جاری کپی می‌شود.
- روی تصویر کوچک بزنید تا تمام‌صفحه باز شود؛ لمس تصویر یا دکمهٔ بازگشت آن را می‌بندد.
- پوشه‌ها و عکس‌ها پس از بستن و باز کردن برنامه باقی می‌مانند. داده‌ها در فضای خصوصی برنامه ذخیره می‌شوند؛ پاک‌کردن داده‌های برنامه یا حذف نصب، این نسخهٔ ساده را حذف می‌کند.
- نام تکراری در یک پوشه پذیرفته نمی‌شود. نام مشابه در پوشه‌ای دیگر اشکالی ندارد.

## نکته‌های فنی

- زبان: Kotlin. رابط کاربری: Android Views و XML (بدون Compose).
- فایل عکس‌ها در `files/images` و فهرست JSON در `files/index.json` فضای خصوصی اپ نگهداری می‌شود.
- انتخاب‌گر تصویر سیستم از `ActivityResultContracts.GetContent` استفاده می‌کند و برنامه هیچ مجوز ذخیره‌سازی گسترده‌ای درخواست نمی‌کند.
- حداقل نسخهٔ Android تعریف‌شده در این پروژه Android 7.0 (API 24) است. فایل‌های Gradle در پروژه موجود است؛ اگر `gradle-wrapper.jar` در ZIP نباشد، Android Studio معمولاً پروژه را با Gradle داخلی خود همگام می‌کند. برای استفاده از دستور `./gradlew` می‌توان در Android Studio از **File > Sync Project with Gradle Files** یا منوی Gradle استفاده کرد تا Wrapper ایجاد/دریافت شود.

## ساخت خودکار APK در GitHub

پس از push کردن پروژه به GitHub، Workflow با نام **Build Android APK** به‌طور خودکار اجرا می‌شود (همچنین برای Pull Request و اجرای دستی در تب Actions). این پروژه Wrapper را در محیط GitHub با Gradle 8.7 تولید می‌کند و سپس APK دیباگ را می‌سازد. در اجرای موفق، فایل را از تب **Actions**، داخل بخش **Artifacts** با نام `PooshehNegar-debug-apk` دریافت کنید.

فرمان ساخت در محیط محلی پس از نصب Gradle نیز `gradle wrapper --gradle-version 8.7` و سپس `./gradlew assembleDebug` است.
